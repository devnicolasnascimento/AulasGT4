# Aulas Geração Tech 4.0

Repositório destinado ao armazenamento e organização das atividades, exercícios e projetos desenvolvidos ao longo do curso de **Desenvolvimento Full Stack — Geração Tech 4.0**.

## 📚 Sobre o projeto

Este repositório reúne os conteúdos e práticas desenvolvidos durante a formação, servindo como um histórico de aprendizado e evolução nas tecnologias abordadas no curso.

Aqui serão disponibilizados exercícios realizados em aula, desafios, projetos e outras atividades relacionadas ao desenvolvimento **Front-end** e **Back-end**.

## 🎯 Objetivos

- Aprender e praticar conceitos de desenvolvimento Full Stack;
- Desenvolver aplicações web;
- Aplicar conceitos de programação na prática;
- Conhecer e utilizar diferentes tecnologias e ferramentas;
- Organizar as atividades desenvolvidas durante o curso;
- Acompanhar minha evolução como desenvolvedor.

## 🛠️ Tecnologias

As tecnologias utilizadas podem variar de acordo com cada atividade. Entre elas:

### Front-end
- HTML5
- CSS3
- JavaScript
- React

### Back-end
- Node.js
- APIs REST

### Ferramentas
